# YTBender — YouTube Content Planner & Offline Studio

An offline-first YouTube trend analyzer, niche topic discovery engine, script & viral hook writer, and 10-day Shorts-to-Long-form upload planner.

## Quick Start

1. Double-click **`Start-App.bat`** in `d:\YT APP` (or run `powershell -ExecutionPolicy Bypass -File "d:\YT APP\server.ps1" -Port 8080`).
2. Open **[http://localhost:8080/](http://localhost:8080/)** in your browser.
3. Alternatively, open **`index.html`** directly in any browser for 100% offline standalone mode.

## 3-Step Creator Workflow

- **Step 1 — Find Topics**: Choose or type your YouTube niche, search live YouTube trends or offline benchmarks, import YouTube Studio CSV analytics, and pick high-retention video topics.
- **Step 2 — Write Script**: Customize tone, pacing, script style, video style, language (`English`, `Hinglish`, `Hindi`, `Spanish`), and format (`16:9 Long-form` or `9:16 45s Shorts`), then edit or read your script in the built-in fullscreen Teleprompter.
- **Step 3 — Upload Plan**: Organize your 10-day Shorts-to-Long-form funnel sequence and track production across the 5-stage Kanban board.
- **Save Work & Settings**: One-click sync to `d:\YT APP\GoogleDrive_Sync` (Markdown script, CSV upload calendar, and JSON workspace backup), plus optional AI Prompt Bridge (`ChatGPT`, `Gemini`, `Claude`) and local `Ollama` support.
